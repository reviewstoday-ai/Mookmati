# Mookmati website

Source files for [mookmati.in](https://mookmati.in), the website of Mookmati: handmade goods from Indian artisans, guided by non-violence (ahimsa).

- Hosted free on GitHub Pages from the `main` branch.
- Orders are placed on WhatsApp. There is no payment system on the site.
- Instagram: [@mookmatistudio](https://www.instagram.com/mookmatistudio/)

## Files

- `index.html`, `shop.html`, `about.html`, `contact.html`: main pages.
- `shipping.html`, `returns.html`, `privacy.html`, `terms.html`: policy pages.
- `style.css`: the design for every page.
- `images/`: product photos, named by product code (for example `MK-BS-001.jpg`).
- `CNAME`: tells GitHub Pages to serve the site on mookmati.in.
